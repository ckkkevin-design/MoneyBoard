# 钱迹看板 MoneyBoard v1.2

一个完全离线、本地存储的 Android 记账 App。

## v1.2 升级
- 首页改成成品化看板：大号“本周期可用预算”卡片
- 环形预算使用进度
- 本周期每日消费趋势折线图
- 消费分类占比环形图 + 分类占比
- 最近 4 笔账目直接显示在首页
- 记一笔页面重新设计：大金额输入、分段按钮、快捷用途标签
- 按钮、卡片、圆角、留白、底部导航全面优化
- 记账周期固定为每月 15 日 00:00 到次月 15 日 00:00
- 预算和目标都按该周期独立保存

## 核心规则
净结余 = 收入 - 消费 - 负债

预算只限制“消费”。

## 数据
所有数据保存于手机本地 SQLite，不需要账号，不需要联网权限。
