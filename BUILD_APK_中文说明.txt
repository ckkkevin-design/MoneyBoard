MoneyBoard v1.3 APK 自动构建说明

你已经会用 GitHub Actions 的话，只需要：

1. 把本项目根目录内容上传 / 覆盖到你的 MoneyBoard GitHub 仓库根目录。
2. 提交 Commit。
3. 点 GitHub 顶部 Actions。
4. 等 Build Android APK 变绿色成功。
5. 点成功任务 -> Summary -> 页面底部 Artifacts。
6. 下载 MoneyBoard-debug-apk。
7. 解压得到 app-debug.apk。
8. 把 app-debug.apk 发到安卓手机，允许“安装未知应用”后覆盖安装。

默认周期：每月15日 00:00 -> 次月15日 00:00。
版本：1.3.0
minSdk：Android 7.0（API 24）
